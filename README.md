# Unit Converter

A very basic command-line unit converter written in Python.

## Supported units

- **Length:** mm, cm, m, km, in, ft, yd, mi
- **Weight:** g, kg, oz, lb
- **Temperature:** c, f, k

## How to run

Requires Python 3 (no extra packages).

```bash
python3 unit_converter.py
```

Then type a conversion like:

```
> 10 km mi
10 km = 6.214 mi
> 100 c f
100 c = 212 f
```

Type `q` to quit.
